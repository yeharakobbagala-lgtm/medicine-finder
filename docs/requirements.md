# Medicine Finder - Requirements

## Customer Features

- Customer registration
- Email verification
- Customer login
- Search medicines
- Search based on customer location
- Find nearby stores
- Check medicine availability
- Get alternative products with the same generic name
- Request unavailable medicine
- Receive email notification when the medicine becomes available

## Agency Features

- Agency registration
- Email verification
- Agency login
- Add store/pharmacy location
- Add medicines and products
- View products
- Update products
- Delete products
- View top 10 selling products

## Technology

- Frontend: React + TypeScript
- Backend: Java + Spring Boot
- Architecture: Microservices + Layered Architecture
- Database: Superbase
- Cache: Redis
